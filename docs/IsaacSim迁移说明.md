# Isaac Sim 迁移说明（2026-11-24）

把训练仿真从 MuJoCo 换到 Isaac Sim（租服务器跑）之前的整理：
- 哪些要重写、哪些不动；
- 要带过去的参数；
- 真机数据告诉我们仿真该对齐什么；
- 迁移步骤和每一步的验收标准。

## 0. 先说结论

1. **今天的真机数据显示，机械臂和夹爪的动力学，仿真和真机基本一致**（见第 3 节）。第一次真机抓取效果差，主因是**训练分布**：v5 没见过静止物体，现场最低档带速 3.6 cm/s 也低于训练下限 4 cm/s。换仿真器本身不会解决这个问题，Isaac 版的训练分布要改（第 4 节）。
2. **部署侧不迁移。** 真机闭环用的运动学孪生（IK、指尖高度、碰撞检查）、标定、step4 虚拟实验室都继续用 MuJoCo。它们只做运动学，在 CPU 上跑，已经在真机上验证过。Isaac Sim 只负责训练。
3. **策略接口不变**：观测字典的键和形状、7 维动作的含义、10 Hz 控制频率都不改。这样在 Isaac 里训练出的策略，可以直接用现有的 step2 回放、step4 干跑和 step6/7 真机流程验证。

## 2. 代码：哪些重写、哪些照搬、哪些不动

| 模块 | 现在 | 迁移后 |
|---|---|---|
| `envs/base_env.py`、`envs/dynamic_grasp.py` | MuJoCo 单环境；SB3 `SubprocVecEnv` 开 8 个 | **重写**成 Isaac Lab 的 GPU 批量环境（几百～几千个并行）。任务逻辑照搬：物体与轨迹、带面、成功判定、奖励、提前结束 |
| `assets/descriptions/nero7/`（MJCF + 网格） | MJCF | **转 USD**。用 Isaac Sim 的 MJCF 导入器，或从 AgileX 官方 URDF 导入，但要把夹爪改成图纸尺寸（见 `SOURCE.md`：夹爪座 50.5 mm、指尖平面 142.5 mm，TCP 在指尖后 10 mm）。两指对称（`finger_symmetry`）在 PhysX 里用 mimic 关节或两个驱动 |
| 执行器 `robot.xml` `<actuator>` | 位置伺服：J1～J3 kp 90 / kv 7，J4 70/6，J5～J6 45/4，J7 40/3.5，力矩 ±100；关节阻尼 1.0、armature 0.005、frictionloss 0.30；夹爪 kp 300 / kv 10，±40 N | 换成 PhysX 关节驱动的刚度/阻尼。**单位和含义不完全一样，不要照抄数值**，按第 3 节的实测响应来调 |
| `sensors/camera.py` 可见性 | 投影 + 深度量程 + `mj_ray` 射线遮挡 | 训练时**不要渲染相机**（几千个环境渲染深度图会把显存吃光），改用射线检测（Isaac Lab 的 RayCaster 或 Warp）做同样的判定 |
| `envs/observation.py`（记忆、测速、观测拼装） | numpy，单环境 | 写一份 torch 批量版本；**numpy 版不能删**，真机还在用。两份要有等价测试：同样的输入，输出差 < 1e-5 |
| `agents/controllers/pd_ee_delta_pose.py`（动作 → IK → 关节目标 → 修正） | MuJoCo 雅可比 + 阻尼最小二乘 | 写 torch 批量版本，**算法和参数照搬**：阻尼 1e-3、姿态权重 0.5、零空间偏向等待位（增益 0.05）、每步 6 次迭代、单步关节变化 ≤ 限速 × 0.1 s、指令在上一步指令上累积、牵引绳 max(3 cm, 1.5 × 步长)、`correct()` 三项修正。部署用的是 MuJoCo 这一份，两边不一致就是新的仿真与真机差距。验收：随机 1000 组状态和动作，和 MuJoCo 版的关节目标差 < 1e-3 rad |
| `grasp_detection/analytic_grasps.py`、`utils/traj_utils.py`、`utils/geometry.py`、`utils/config.py` | 纯 numpy | 照搬（批量化时可以每回合在 CPU 上生成，再拷到 GPU） |
| `algorithms/Networks/`（抓取点组编码器） | torch | 照搬 |
| `algorithms/scripts/sac_train.py` | SB3 SAC | 建议继续用 SB3：Isaac Lab 有 SB3 的向量环境包装，存下来的 `.zip` 现在的部署代码（`runtime/session.py::load_policy`）能直接读。如果换成 skrl / rsl_rl，要给 `load_policy` 写一个适配层 |
| `sim2real/` 全部（标定、部署、虚拟实验室） | MuJoCo 运动学 | **不动** |

## 3. 真机实测：仿真要对齐的量

数据来自 2026-11-22 的离线录制和 2026-11-24 的闭环日志（目录见 [数据清单.md](数据清单.md)）。“当前仿真”指 MuJoCo 版的 v5/v6 环境，和真机用同一种方法测。

| 量 | 真机 | 当前仿真 | 对 Isaac 版的要求 |
|---|---|---|---|
| 关节跟随滞后（10 Hz 指令与实测，最佳平移） | J1～J7 90～100 ms（全速闭环，7 段） | 80～110 ms（step4 grasp 档） | **已经一致**，按这个调 PhysX 驱动参数 |
| 关节跟随滞后（step5，100 Hz 发送口径） | 255 ms（J3，慢速 ×0.3） | 215 ms | 同上 |
| 关节稳态误差 | 停 0.6 s 后 0.1～0.7°，TCP 偏低 2～5 mm（重力方向） | 没单独测过 | 仿真里也要有重力下沉；可以对驱动刚度做 ±20% 随机化 |
| 关节速度（全速闭环 99 分位） | 0.4～1.0 rad/s，远低于厂家限速 3.1～3.9 rad/s | — | 限速照厂家值 |
| 夹爪闭合 | 10 → 5 → 0.8 cm（每 0.1 s，夹空时）；张开约 0.3 s | 10 → 4.9 → 0.7 cm | **已经一致** |
| 夹爪宽度换算 | 读数 = 指令（5.0 / 10.0 cm） | 宽度 = 2 × 单指行程 | 两指实际间距还没用尺子量，量了再定 |
| 相机延迟 | 0.08 s（标定 step3） | 0（观测没有延迟） | 观测随机延迟 0～0.12 s |
| 感知位置噪声（单帧，物体中心） | x 2～3 mm，y 3～5 mm，z 5～7 mm | 抓取位姿 4 mm（各向同性）+ 测速用 2 mm | z 噪声加大到约 6 mm |
| 感知尺寸噪声 | 单帧轮廓约 1 cm；10 帧中位数后 < 5 mm | 没有（抓取由真值尺寸生成） | 每回合给观测用的尺寸加 ±3～5 mm 偏差 |
| 带面高度 | 独立实测 −0.120；腕部相机 −0.112；今天物体底面 −0.111～−0.116 | 固定 −0.120 | 随机 ±5 mm；部署安全带面仍取 −0.112 |
| 现场带速 | 3.6 / 9.6 / 13.3 cm/s | 训练 4～50 cm/s | 见第 4 节 |
| 护栏 | 用户说明“很矮，约等于没有” | 两侧 1.5 cm | 随机 0～1.5 cm |
| 控制循环计算 | 每拍中位 27 ms，最大 51 ms（一拍 100 ms） | — | 不是瓶颈 |

## 4. 第一次真机抓取的教训 → Isaac 版训练分布

2026-11-24 的 step7 结果：4 次执行，抓起 1 回合；操作者拍了 2 次急停；其余回合都是夹空后重试。逐拍分析见 `闭环阶段.md` B4。

1. **加入静止物体和慢带。** 策略对静止物体的固定动作是：先往下游走，再一边快速下降一边往上游冲过物体，闭合时夹空，物体被手指推走。
   - 训练带速改成 0～50 cm/s，其中约 15% 的回合是静止物体；
   - 现场三档附近（3～15 cm/s）加权，约占 40%。
2. **限制靠近带面时的下降速度。** 两次急停都发生在高速下降（约 35 cm/s）到物体正上方时。可以在奖励里罚“指尖离带面 < 5 cm 时的竖直速度”，或者在动作映射里让竖直步长随高度减小。这一条也会让真机操作更安心。
3. **训练用的指尖余量改成 8 mm。** 部署抓取档已经是 8 mm（step5 测到关节下沉 2～5 mm），训练还是 3 mm，两边不一致。
4. **回合时长 12 s**（2026-11-24 已改 `default.yaml`）。
5. **物体被碰后的物理。** 今天真机上物体被推了 5～15 cm、被推到护栏边。这正是想换 Isaac Sim 的原因（接触物理）。迁移后先用脚本让手指推一下静止物体，看滑动距离和真机是否同一个量级，再开始训练。摩擦系数随机 0.5～1.2。
6. **起始位姿**按 v6 的等待位（中心线往远侧 8 cm、带面上 28 cm），真机已按它摆位。

## 5. 迁移步骤和验收

| 步骤 | 内容 | 验收 |
|---|---|---|
| M0 | 服务器装 Isaac Sim + Isaac Lab，跑通官方示例 | 官方示例能训练 |
| M1 | NERO7 + 夹爪转 USD | 随机 1000 组关节角，Isaac 和 MuJoCo 的 TCP、相机位姿差 < 0.5 mm / 0.1°；关节限位一致 |
| M2 | 单环境场景：带面会动、两侧护栏、长方体/圆柱、轨迹驱动、碰到就脱离驱动 | 脚本 PBVS 基线，同一批种子（20000 起 100 回合）成功率和 MuJoCo 的 19%（现场带速 63%）在 ±10% 以内 |
| M3 | 批量的观测、控制器、可见性 | 和 numpy / MuJoCo 版的等价测试通过（第 2 节） |
| M4 | 驱动参数对齐 | 复现 step5 的 ±3 cm 小动作：滞后 90～110 ms（10 Hz 口径），夹爪 0.2 s 闭到 1 cm |
| M5 | 按第 4 节的分布训练 SAC | 在 MuJoCo 的 step4 虚拟实验室里（真机那套代码）跑，现场带速成功率超过 v5 的 89.5%；静止物体单独统计 |
| M6 | 回到这台电脑：step2 回放真机录制、step4 干跑、step6/7 真机 | 按 `闭环阶段.md` 的流程 |

M5 要在 MuJoCo 虚拟实验室里验收，而不只看 Isaac 自己的评估。原因是：v6 在训练环境里 86.7%，到部署路径上只有 73%；部署路径才是真机会走的那条。

## 6. 还没解决、带过去的问题

1. v6 纯仿真 86.7% → 闭环干跑 73% 的掉点原因没查清（v5 两边差不多）。Isaac 版也可能出现同样的问题，所以 M5 必须在部署路径上验收。
2. 夹爪两指实际间距还没用尺子量（`runtime/devices.py` 的宽度换算）。
3. 解析抓取只支持长方体和圆柱；换成点云抓取检测（GAP-RL 的 LoG）是另一件事，和换仿真器无关。
4. GAP-RL 的 goal_aux 辅助损失还没移植。
