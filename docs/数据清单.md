格式：
- 每个录制或闭环目录里都有 `meta.json`（相机内参、配置、模型、档位）和 `frames.jsonl`（每帧时间戳、关节角）；
- 深度图在 `depth/`（16 位 PNG，单位 mm），彩色图在 `color/`；
- `joints_hist.npz` 是 100 Hz 的关节历史；
- 闭环目录另有 `ticks.jsonl`（每拍的观测、动作、指令、修正）和 `episodes.json`；
- 回放后会生成 `replay_report.json` 和 `replay.mp4`。
